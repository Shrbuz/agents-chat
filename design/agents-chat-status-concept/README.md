# Agents Chat 托盘与状态窗口设计稿

这是一套独立高保真设计稿，没有修改现有托盘宿主、状态接口或业务逻辑。

## 设计方向

- 产品：本机多项目、多角色会话的通信与调度中枢
- 性格：克制、精确、像一台有生命的仪表
- 世界：信号中继台，而不是普通聊天软件
- 视觉时刻：会话拓扑中的任务脉冲和实时事件轨迹
- 专属识别：三节点中继标记；形状固定，以颜色表示运行、执行、告警、离线

## 画板

打开 `index.html` 后可切换三个画板：

1. **状态窗口**：项目导航、健康摘要、实时会话拓扑、最近活动、会话详情与操作
2. **托盘面板**：按项目折叠的会话列表、异常摘要和常用入口
3. **图标系统**：主标记、状态色、16–64px 尺寸和 Windows 托盘预览

状态窗口中的四个会话节点可点击，右侧详情会随选择变化。托盘和详情按钮会显示原型反馈。

## 动效规格

- 状态轮询：沿用当前 3 秒节奏；更新只做 140–180ms 的颜色/透明度过渡
- 任务投递：圆点沿真实路由移动，2.2–4.6 秒；只有存在事件时播放
- 执行中：头像状态点出现缓慢扩散环；任务条在节点内部移动
- 新事件：活动行淡入并上移 4px，180ms
- 窗口与托盘：打开 180ms，透明度 0→1、Y 4px→0
- `prefers-reduced-motion` 下禁用所有持续动画

## 信息层级

- 第一层：中枢是否运行、在线角色、执行中、等待任务、最近投递
- 第二层：项目与角色拓扑，谁在执行、谁需处理
- 第三层：适配器、传输、模式、会话 ID、失败次数等诊断信息

原先 12 列状态表中的字段没有丢失，只是从同一平面拆到摘要、节点和详情面板中。

## 颜色

- 背景：`#090B0D`
- 主窗口：`#101316`
- 主文字：`#EDF2F4`
- 次文字：`#A9B3BA`
- 中继/在线：`#63DDD0`
- 执行中：`#83B7FF`
- 需留意：`#F2BD66`
- 故障：`#F07C78`
- 离线：`#69747C`

所有状态同时使用位置、形状和文字，不仅依赖颜色区分。

## 下一阶段建议

设计确认后再进入实现。实现时建议保留现有 Broker/status 数据接口，先重做 WinForms 宿主的绘制层和窗口结构，再补充动画与托盘状态图标，避免同时改 UI 和通信逻辑。
